# Security policy

## Supported versions

Only the latest release, as published on the Chrome Web Store and in this repository, receives security fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub instead: on this repository's **Security** tab, click **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply within a week. Once a fix ships, the report can be disclosed together with credit to you, if you'd like.

Some issues matter especially here: a web page controlling the extension, the extension gaining access to a tab the user didn't click it on, or audio being captured without the user's consent.
